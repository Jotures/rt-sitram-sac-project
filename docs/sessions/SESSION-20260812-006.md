## Entorno e investigación oficial

- Entorno comprobado: Node.js `v24.12.0`, npm `11.6.2`, pnpm `11.19.0`, Corepack `0.34.5` y Git `2.52.0.windows.1`; Yarn no estaba instalado.
- [Node.js Releases](https://nodejs.org/en/about/previous-releases): Node 24 es LTS; se fijó la línea 24 LTS.
- [Vite Getting Started](https://vite.dev/guide/): Vite requiere Node 20.19+ o 22.12+; el runtime disponible es compatible. La [plantilla oficial React/TypeScript](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) confirma React 19.2, TypeScript 6 y Vite 8 como combinación vigente.
- [React Versions](https://react.dev/versions) y [TypeScript 6.0](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-6-0.html): se eligieron React 19.2.8 y TypeScript 6.0.2.
- [PowerSync JavaScript Web SDK](https://docs.powersync.com/client-sdks/reference/javascript-web): es compatible con React y otras SPA, utiliza SQLite local en navegador y depende de APIs de navegador; no condiciona Vite/React ni se integra aún.
- [Supabase JavaScript installation](https://supabase.com/docs/reference/javascript/installing): `@supabase/supabase-js` se distribuye mediante pnpm; no hay restricción evidente para el cliente Vite. No se instaló ni configuró.
- [PWA installation](https://web.dev/learn/pwa/installation): manifest e instalación dependen de requisitos del navegador. Se difieren manifest y service worker para la siguiente sesión, manteniendo explícita la separación entre caché PWA y SQLite empresarial.

No existe una razón material para apartarse del stack Accepted.
