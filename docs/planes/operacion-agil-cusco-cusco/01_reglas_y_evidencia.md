# Reglas y evidencia

El propietario confirmó que la unidad sale de Cusco con un fondo para viáticos y
otros gastos, puede recibir depósitos adicionales durante la ruta y rinde todos
los gastos cuando retorna a Cusco. Los fletes de ida y retorno se administran por
cliente y servicio, independientemente de esa rendición.

La evidencia de WhatsApp respalda hojas tituladas `Cusco–Lima–Cusco`,
`Cusco–Corire–Cusco`, `Cusco–Pisco–Lima–Cusco` y
`Cusco–Challhuahuacho–Ilo–Corire–Cusco` (referencias WAM-00029, WAM-00030,
WAM-00208 y WAM-00550). Es evidencia de comprensión, no una fuente para importar
transacciones ni inferir saldos históricos.

## Reglas aceptadas

- Una salida es la responsabilidad operativa de una unidad y conductor desde la
  partida hasta el regreso.
- Una salida puede contener cero, uno o varios servicios comerciales.
- Cada servicio conserva cliente, carga, flete y cobranza propios.
- El fondo y sus ampliaciones pertenecen a la salida y tienen una rendición
  conjunta.
- El combustible identifica si lo pagó la empresa o el fondo del conductor.
- Una rendición pendiente no bloquea una nueva salida y nunca se compensa sola.
- El kilometraje es opcional; no se reemplaza una ausencia por cero ni por una
  lectura anterior.
- Foto y resumen son una transcripción revisable; no se ejecuta OCR.
