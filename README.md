# Centro de Control Digital R&T

Repositorio del sistema digital de control operativo de R&T SITRAM SAC.

- `docs/` es el área de conocimiento y gobierno; los documentos existentes son autoritativos.
- `implementation/` contiene exclusivamente la implementación ejecutable.
- [docs/mapa_repositorio.md](docs/mapa_repositorio.md) orienta rápidamente hacia el módulo, entrada y prueba correctos para cada tipo de tarea.
- [AGENTS.md](AGENTS.md) gobierna el trabajo de Codex.
- Las decisiones duraderas se registran en [docs/decisions/index.md](docs/decisions/index.md).
- Las sesiones de trabajo se registran en [docs/sessions/index.md](docs/sessions/index.md) y su estado actual en [docs/sessions/current.md](docs/sessions/current.md).
